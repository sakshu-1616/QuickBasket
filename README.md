QuickBasket – Online Food Ordering System (JSP + Servlet + MySQL)

QuickBasket is a simple online food ordering web application built using JSP, Servlets, and MySQL.
Users can browse food items, add them to cart, place orders, and view their order history.
Admins can manage food items and view all user orders.

Features
User Side

User Registration

User Login

View Food Menu

Add items to Cart

Update/Remove items from Cart

Place Order

View Order History

Admin Side

Admin Login

View All Orders

Add New Food Items

Delete/Manage Orders

Technology Used

Frontend: JSP, HTML, Inline CSS

Backend: Java Servlets

Database: MySQL

Server: Apache Tomcat 8.5

JDBC Driver: MySQL Connector/J

Database

Database Name: quickbasket

Main tables:

users

admins

food_items

orders
